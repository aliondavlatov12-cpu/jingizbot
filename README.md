# Jingizbot

Авторассылка аз аккаунти корбар ба гурухҳо.

## Насб

1. `pip install -r requirements.txt`
2. `.env.example` → `.env`, пур кун
3. `python bot.py`

## Танзим

Дар `.env`:
- `BOT_TOKEN` — аз @BotFather
- `API_ID`, `API_HASH` — аз my.telegram.org
- `SUPER_ADMINS` — ID-и админҳо

## Функсияҳо

- Пайваст кардани аккаунти корбар (userbot)
- Рӯйхати гурухҳо ва интихоб
- Рассылка бо фосилаи 2–20 дақиқа
- Таймер-рассылка
- Обунаи ҳатмӣ (force-subscribe)
- Ситораҳо ва нархҳо (админ муайян мекунад)
- Админ-панел: корбарон, ситора, нархҳо, экспорт CSV
- Рассылка аз номи ҳар корбар (админ)
