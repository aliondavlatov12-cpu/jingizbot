# JingizBot — Telegram auto-broadcast bot

Python 3.11+, aiogram 3, Telethon StringSession, asyncpg/PostgreSQL ва aiohttp health server.

## Функсияҳо
- Пайваст кардани аккаунти Telegram бо рақам, коди Telegram ва 2FA.
- Гирифтан ва интихоб кардани гурӯҳҳои аккаунт.
- Рассылка ба гурӯҳҳои интихобшуда бо фосилаи 2–20 дақиқа.
- Имзои `отправлено через @jingizbot`, фосилаи танзимшаванда ва таймер.
- Админ-панел: корбарон, админҳо, ситораҳо, нархҳо, force-subscribe, рассылка, CSV ва омор.
- Админҳо аз санҷиши нарх озоданд.
- PostgreSQL cloud; session-ҳо ҳамчун StringSession дар база нигоҳ дошта мешаванд.
- `/` ва `/health` барои Render health check.

## Муҳим пеш аз истифода
Session-и Telethon ба аккаунти Telegram дастрасӣ медиҳад. `DATABASE_URL`, `BOT_TOKEN`, `API_HASH` ва session-ҳои база махфӣ мебошанд. Ба касе надиҳед. Боти худро танҳо барои гурӯҳҳое истифода баред, ки дар онҳо паём фиристодан иҷозат аст. Telegram метавонад маҳдудиятҳои FloodWait ё дигар маҳдудиятҳоро татбиқ кунад; код ҳангоми FloodWait рассылкаро қатъ мекунад.

Таймерҳо ва рассылкаҳо дар хотираи раванд иҷро мешаванд. Агар Render хоб равад ё deploy/restart шавад, вазифаи ҳозираи дар хотира иҷрошаванда қатъ мешавад; сабти вазифа дар PostgreSQL мемонад, аммо автоматӣ аз нав барқарор кардани таймерҳои гузашта дар ин версия вуҷуд надорад. Барои кори доимӣ Render Free метавонад мувофиқ набошад.

## 1. Neon PostgreSQL
1. Дар https://neon.tech аккаунт ва project созед.
2. Connection string-и PostgreSQL-ро гиред. Агар пешниҳод шавад, URL-и pooled connection-ро интихоб кунед.
3. Дар Render ҳамчун `DATABASE_URL` гузоред. `sslmode=require` бояд фаъол бошад.

## 2. Telegram API
1. `BOT_TOKEN`-ро аз @BotFather гиред.
2. `API_ID` ва `API_HASH`-ро аз https://my.telegram.org гиред.
3. `SUPER_ADMINS` — Telegram numeric ID-и админҳои асосӣ, бо вергул ҷудо.

## 3. Deploy дар Render
1. Лоиҳаро ба GitHub гузоред.
2. Render → New → Web Service → repository.
3. Build Command: `pip install -r requirements.txt`
4. Start Command: `python bot.py`
5. Environment Variables-ро аз `.env.example` илова кунед.
6. Health Check Path: `/health`
7. Барои `PORT` Render-и пешниҳодкардаро истифода баред; агар он автоматӣ дода шавад, код онро мехонад.

## 4. Истифода
- Ба бот `/start` фиристед.
- Пайваст кардани аккаунт → рақам → код → 2FA агар талаб шавад.
- «🔄 Навсозии гурӯҳҳо» ва баъд «👥 Гурӯҳҳо».
- Гурӯҳҳоро бо пахш кардан интихоб кунед.
- «📨 Рассылка» барои фиристодани матн.
- Админ: `/admin` ё тугмаи «👑 Админ-панел».

## 5. Нархи функсияҳо
Дар админ-панел → «💰 Нархҳо». `0` маънои ройгон барои ҳама. Админҳо ҳамеша аз ситораҳо озоданд, новобаста аз нархҳои гузошташуда.

## 6. Force-subscribe
Дар админ-панел → «📢 Обунаи ҳатмӣ» → «➕ Илова». Бот бояд ба канал/гурӯҳ илова шуда бошад ва барои санҷидани аъзо дастрасӣ дошта бошад. Барои каналҳои хусусӣ, корбар бояд тавассути даъватнома дастрасӣ дошта бошад; ин версия барои истиноди хусусӣ санҷиши аъзоро бо ID-и дуруст талаб мекунад.

## 7. Тағйир додани нархи функсия
Тугмаи функсияро пахш кунед ва адади ситораро фиристед. Танҳо админ метавонад нархро тағйир диҳад.

## Эзоҳҳо
- Ин лоиҳа бидуни SQLite кор мекунад.
- `StringSession` дар PostgreSQL нигоҳ дошта мешавад.
- Ситораҳои дохили бот баланси дохилӣ мебошанд; онҳо ба Telegram Stars-и расмӣ пайваст нестанд.
- Агар пароли 2FA нодуруст бошад, воридшавӣ такрор карда мешавад. Барои қатъ кардани раванди ноком, аз нав `/start` фиристед.
