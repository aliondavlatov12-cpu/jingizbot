# VertonaBot — Telegram-бот для рассылки

Python 3.11+, aiogram 3, Telethon StringSession, asyncpg/PostgreSQL и aiohttp health server.

## Исправления в этой версии
- Исправлен ID обычных Telegram-групп: ранее они сохранялись положительным числом, из-за чего отправка могла идти не в группу.
- Отправитель теперь сначала загружает диалоги текущей Telethon-сессии и сопоставляет группы по marked peer ID; это предотвращает частую ошибку `Could not find input entity` при использовании StringSession.
- При обновлении списка групп старые ошибочные ID обычных групп переносятся на правильные отрицательные ID с сохранением выбора.
- Ошибка одной группы (нет прав, группа недоступна, RPC-ошибка) не прерывает отправку в остальные выбранные группы.
- При FloodWait/Slow Mode отправитель соблюдает указанный Telegram период ожидания, повторяет попытку и затем продолжает очередь; авторассылка не завершается из-за одной неудачной группы.
- Авторассылка переживает временную ошибку отдельного цикла и пробует следующий цикл после выбранного интервала.
- Активная авторассылка сохраняется в PostgreSQL и восстанавливается после обычного перезапуска/повторного развёртывания; ручная остановка сохраняет статус «выключена».
- Добавлены журналы начала/конца каждого цикла, времени ожидания и результата отправки в группы.

## Возможности
- Подключение Telegram-аккаунта по номеру телефона, коду Telegram и паролю 2FA при необходимости.
- Код входа можно вводить в формате `52.301`: точка и другие разделители автоматически удаляются перед передачей кода Telegram API.
- Загрузка и выбор групп подключённого аккаунта.
- Рассылка текстовых сообщений только в выбранные группы. Интервал между отправками в группах для обычной рассылки и интервал авторассылки настраиваются отдельно (2–20 минут). В авторассылке сообщения отправляются по выбранным группам без дополнительной паузы между группами, затем бот ждёт заданный интервал между циклами.
- Подпись `отправлено через @VertonaBot`, настройка интервала и таймер.
- Панель администратора: пользователи, администраторы, звёзды, цены, обязательная подписка, рассылки, экспорт CSV и статистика.
- Все функции для администраторов бесплатны.
- PostgreSQL; сессии Telethon хранятся в базе в формате StringSession.
- Маршруты `/` и `/health` для проверки состояния на Render.

## Безопасность и ограничения
StringSession предоставляет доступ к Telegram-аккаунту. Не публикуйте `DATABASE_URL`, `BOT_TOKEN`, `API_HASH` и сессии из базы. Никому не сообщайте код входа или пароль 2FA. Пароль 2FA бот не сохраняет в базе данных. Используйте рассылку только в группах, где у аккаунта есть право отправлять сообщения. Telegram может применять FloodWait и другие ограничения; код соблюдает время ожидания Telegram. Авторассылка работает только в выбранных группах, где подключённый аккаунт уже состоит и имеет право отправлять сообщения. Она не вступает автоматически в посторонние группы.

Обычная разовая рассылка и таймер выполняются в памяти процесса и не восстанавливаются после перезапуска. Активная авторассылка сохраняется в PostgreSQL и восстанавливается при следующем запуске процесса. Однако если сервис Render Free уснёт из-за отсутствия входящего трафика, бот не сможет отправлять сообщения во время сна; для непрерывной работы используйте постоянно работающий план или Background Worker. Ҳангоми истифодаи авторассылка танҳо гурӯҳҳоеро интихоб кунед, ки дар онҳо барои фиристодани чунин эълонҳо иҷозат доред. Ҳеҷ гуна кафолати фиристодани 100% вуҷуд надорад: ҳуқуқҳои гурӯҳ, FloodWait, пайвастшавӣ ва маҳдудиятҳои Telegram метавонанд ба фиристодан таъсир расонанд.

## 1. Neon PostgreSQL
1. Создайте проект на https://neon.tech.
2. Скопируйте строку подключения PostgreSQL; при наличии выберите pooled connection.
3. Добавьте её в Render как `DATABASE_URL`. Для внешнего подключения должен быть включён SSL (`sslmode=require`).

## 2. Telegram API
1. Получите `BOT_TOKEN` у [@BotFather](https://t.me/BotFather).
2. Получите `API_ID` и `API_HASH` на https://my.telegram.org.
3. Укажите `SUPER_ADMINS` — числовые Telegram ID главных администраторов через запятую.

## 3. Развёртывание на Render
1. Загрузите проект в GitHub.
2. В Render выберите **New → Web Service** и подключите репозиторий.
3. Build Command: `pip install -r requirements.txt`
4. Start Command: `python bot.py`
5. Добавьте переменные окружения из `.env.example`.
6. Health Check Path: `/health`.
7. Используйте переменную `PORT`, которую предоставляет Render.

## 4. Использование
1. Отправьте боту `/start`.
2. Нажмите «🔗 Подключить аккаунт», отправьте номер телефона, затем код Telegram и пароль 2FA, если он запрошен.
3. Нажмите «🔄 Обновить группы», затем «👥 Группы» и выберите нужные группы.
4. Нажмите «📨 Рассылка» и отправьте текст.
5. Для авторассылки откройте «🤖 Авторассылка», выберите интервал от 2 до 20 минут, нажмите «▶️ Запустить» и отправьте текст. Панель показывает «🔴 Отключена» или «🟢 Включена»; во время работы доступна кнопка остановки. Интервал отсчитывается после завершения полного цикла по выбранным группам.
6. Администратор может открыть панель командой `/admin` или кнопкой в меню.

## 5. Цены и администраторы
В панели администратора откройте «💰 Цены». Значение `0` означает бесплатное использование для обычных пользователей. Администраторы всегда освобождены от оплаты независимо от установленных цен.

## 6. Обязательная подписка
В панели администратора откройте «📢 Обязательная подписка» → «➕ Добавить». Бот должен состоять в канале/группе и иметь право проверять участников. Для кнопки подписки предпочтительна публичная ссылка или username.

## 7. Примечания
- Проект не использует SQLite.
- Сессии Telethon хранятся в PostgreSQL.
- Внутренние звёзды бота — это внутренний баланс, не связанный с официальными Telegram Stars.
- Если пароль 2FA неверен, бот предложит повторить ввод. Чтобы прервать подключение, отправьте `/start`.
