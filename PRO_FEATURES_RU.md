VertonaBot PRO — возможности тарифа

- Все платные функции бота без списания Stars: подключение аккаунта, рассылка, таймер, обновление/загрузка групп и любые другие операции, подключённые к тарифному механизму.
- Бесплатное отключение подписи «Отправлено через @VertonaBot».
- Выбор групп без тарифного ограничения, с постраничным списком.
- Авторассылка, автоответчик, изменение текста, настройка интервала и другие доступные функции бота.
- Отображение даты окончания PRO.
- Администратор выдаёт PRO по Telegram ID на заданное число дней; повторная выдача продлевает текущий срок.
- Отдельный список активных PRO-пользователей в админ-панели.
- Уведомления при выдаче, удалении и окончании PRO.

Важно: PRO не снимает ограничения Telegram, FloodWait, Slow Mode, права на отправку или запреты конкретных групп. Уведомление в личный чат может не доставиться, если пользователь ещё не запускал бота.
